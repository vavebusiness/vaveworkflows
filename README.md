# Vave public-safe launch preview

This folder is a **sanitized public version** of Vave Workflow Store for optional GitHub Pages publishing. It intentionally omits internal affiliate/partner/client records, private metrics, customer contact data, scenario IDs, pending email drafts, and server secrets.

- Products are explicitly marked as in-development previews, not ready to buy.
- The `gh-pages` branch should contain only the files in this folder.
- All pages are public if GitHub Pages is enabled, even when the repository itself is private.
- Product changes in the private HQ are not synced automatically; regenerate and review this copy before republishing.
